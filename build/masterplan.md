# Masterplan: pfarr-tools/roo-ruling

## 1. Goal

Create a small reusable Composer package that renders school handwriting rulings into documents generated by PHPWord. The initial scope reproduces the supplied German primary-school Grade 1-3 lineatures and supports DOCX and ODT.

## 2. Design principles

1. **Geometry first.** A ruling is described in millimetres, not in Word-specific units.
2. **Renderer separation.** `RulingDefinition` contains no PHPWord classes.
3. **Presets, not special cases.** Grade 1-3 are named presets backed by generic geometry.
4. **Vector output.** Never use lineature PNGs as the production implementation.
5. **DOCX and ODT parity.** Features accepted into the public API should work with both PHPWord writers, or be explicitly documented as format-specific.
6. **Composable.** A ruling can occupy part of a worksheet; it is not limited to a full-page stationery template.

## 3. Phase 1 — implemented in this package

- `RulingDefinition`
- `RulingPreset` Grade 1-3
- measured `ReferenceGeometry`
- mm ↔ twip conversion
- fixed-layout PHPWord table renderer
- optional one-string-per-band text insertion
- DOCX/ODT writer helper
- example generator for six sample documents
- basic unit and integration tests
- source-geometry documentation

## 4. Phase 2 — visual regression

After `composer install`:

1. Run `php examples/generate.php`.
2. Render the three generated DOCX files through LibreOffice to PNG.
3. Render the three generated ODT files likewise.
4. Detect horizontal lines and compare their y positions against the measured source references.
5. Accept a maximum geometry deviation of 0.2 mm within a band and 0.3 mm cumulative over a page.
6. If LibreOffice imposes minimum cell heights or paragraph padding, compensate in the renderer rather than modifying semantic preset dimensions.

Recommended future test utility: `tests/Visual/compare_ruling.py`.

## 5. Phase 3 — richer writing support

- per-band callbacks/content objects rather than only strings;
- baseline-aware sample text;
- configurable font and text offset;
- dashed or coloured guide lines;
- no side borders where required;
- mixed rulings in one document;
- automatic count from available section height.

## 6. Phase 4 — additional rulings

Keep the package generic enough to add:

- other German primary-school lineatures;
- simple ruled paper;
- double ruling;
- squared/graph ruling if desired;
- custom user-defined geometry.

These should be new definitions/presets, not new renderer branches unless the geometry truly requires a different primitive.

## 7. Roo integration

Roo should depend on this package rather than duplicate lineature code. A worksheet/document service can select a `RulingPreset` (or later a custom definition) and pass the relevant PHPWord section to `RulingRenderer`.

Suggested persisted value in Roo: the stable preset string (`grade-1`, `grade-2`, `grade-3`) rather than a PHP enum serialization.

## 8. Release checklist

- Composer metadata valid.
- PHPUnit green.
- Six example files generated.
- DOCX visually checked.
- ODT visually checked.
- Geometry regression within tolerance.
- README API examples current.
- GPL-3.0-or-later license included.
